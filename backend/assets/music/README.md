# PostReady instrumental presets

Five original, synthesized 16-second instrumental miniatures composed for this
project. No third-party compositions, samples or recordings are used. The source
score/synthesis script and exported WAV recordings are distributed under the
repository's MIT license. Run `python backend/assets/music/generate.py` to rebuild.

Names describe the intended instrumental style; these are synthesized previews,
not recordings of live performers. They loop or trim to the selected ad duration.
